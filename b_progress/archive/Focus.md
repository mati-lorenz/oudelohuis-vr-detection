# Trials
- DN: it's the dataset with the neural measurement and with the stimulus values in a range where is meaningful to investigate perception
	- DM, DP: serve as confirmation for results about performance and behavioral variables, but not related with perception (stimulus range is a confounder)
- Engaged trials: 
	- Disengaged trials: could provide a null hypothesis for attention-related results
- Noise trials: within this values, stimulus range is narrow enough to simplify regressing it out from perception analyses
	- 0-100 trials: to compare with DM and DP
